# Acceptance Gate

Review the current repository state against the active gate or milestone.

Return:
1. Gate name
2. Evidence found in code/tests/docs
3. Missing pieces
4. Hard blockers
5. Confidence level
6. Recommended next step

Be conservative. This is a gate review, not a motivational speech.
